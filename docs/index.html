✨ Key Features

📝

Text → Video

Generate high-quality videos from natural language prompts using a 14B parameter diffusion transformer model.

🖼️

Image → Video

Animate any still image with natural, physics-aware motion using the SkyReels I2V pipeline.

🪄

LLM Prompt Enhancer

Qwen2.5 LLM automatically expands short prompts into rich cinematic descriptions for better output quality.

⚡

TeaCache Acceleration

~3× faster inference using TeaCache with minimal quality loss — configurable threshold for speed/quality tradeoff.

📦

Async Job Queue

Submit multiple jobs simultaneously. GPU processes them one at a time with real-time status tracking.

🔌

REST API + Swagger

Full FastAPI backend with auto-generated Swagger docs, video streaming, health checks, and job management.

📡 REST API

# Submit a Text-to-Video generation job curl -X POST http://localhost:8000/generate \ -F "prompt=A majestic eagle soaring over mountains at golden hour" \ -F "resolution=540P" \ -F "use_prompt_enhancer=true" # Response { "job_id": "abc-123", "status": "queued", "queue_position": 1 } # Poll for result curl http://localhost:8000/jobs/abc-123 # Response when done { "status": "done", "video_url": "/videos/abc-123.mp4", "duration_sec": 142.3, "enhanced_prompt": "Close-up shot of a bald eagle..." }
